# Geographic data

Generated by `packages/server/scripts/build-zip-data.ts` (`pnpm geo:build`). Do not edit by hand.

| File | Contents |
|---|---|
| `zip5.json` | 40977 five-digit ZIP codes: `zip → [city, stateCode, countyFips, lat, lng]`. `countyFips` is the 5-digit county FIPS code (2-digit state FIPS plus 3-digit county code). Coordinates are GeoNames ZIP centroids rounded to 4 decimal places. |
| `counties.json` | 3147 counties: `countyFips → [name, stateCode]`, used by `countiesByState()`. |

## What was kept

The 50 states and the District of Columbia. Dropped rows: 513 outside the 50 states and DC (territories and APO/FPO military codes), 0 without a county code, 0 duplicate ZIP codes (the first row wins) and 0 malformed rows.

## Known limits

- One county per ZIP code. A ZIP code that spans counties resolves to the county GeoNames lists for it; the HUD-USPS crosswalk (data model §4, `zip_county_map`) is not imported yet.
- City names are GeoNames place names as published (for example "Jbphh" for Joint Base Pearl Harbor-Hickam).
- Distances use straight-line (haversine) distance between ZIP centroids, not driving distance.
